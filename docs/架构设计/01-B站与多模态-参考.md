## 三、核心实现

### 3.1 WBI 签名（`wbi.ts`，128 行）

**背景**：B站对敏感接口（`x/space/arc/search`）强制要求 wbi 签名，无签名则 HTTP 412。

**算法流程**：

```
1. GET /x/web-interface/nav（带Cookie）→ 拿 wbi_img.img_url + sub_url
2. 提取 URL 中 /wbi/<key>.png 的 <key>（共32字符）
3. img_key + sub_key 按 MIXIN_KEY_ENC_TAB 偏移表重排 → mixin_key（32字符）
4. 待签名参数：现有 query + wts=unix秒，每个value过滤 ! ' ( ) * 后按key排序
5. 拼成 k1=v1&k2=v2&...
6. encodeURIComponent(整个string) → md5(encoded + mixin_key) → w_rid
7. 把 wts + w_rid 加回URL
```

**关键代码**：`src/lib/bilibili/wbi.ts`

### 3.2 Cookie 注入（`cookie.ts`，20 行）

```ts
export function getBiliCookie(): string | undefined {
  const sessdata = process.env.BILI_SESSDATA
  const biliJct = process.env.BILI_BILI_JCT
  const dedeUserId = process.env.BILI_DEDE_USER_ID
  if (!sessdata) return undefined
  return `SESSDATA=${sessdata}; BILI_JCT=${biliJct}; DEDE_USER_ID=${dedeUserId};`
}
```

```ts
// code === -799 → 等 RETRY_DELAYS_MS[attempt] 后重试
// 共3次重试（15s → 30s → 60s）

```

### 3.4 RSSHub 兜底（`rss.ts`，254 行）

当 B站 API 全部风控时，降级到 RSSHub 公共实例（无需 cookie/wbi）：

```
URL:    https://rsshub.app/bilibili/user/video/{uid}
触发:   API 3次重试全失败 / 单UP主拿到0条视频
覆盖:   全部7个UP主
数据:   不如API（有标题/时间/链接，无desc/字幕）
```

### 3.5 写入保护（`storage.ts`，149 行）

B站风控时**绝不覆盖上次成功数据**：

```
逐UP主合并规则：
  - 本次 news > 0 且 ok → 覆盖
  - 本次失败 → 沿用旧数据，记入 restored 列表
  - 全部失败 → 记入 failed 列表
```

### 3.6 跨模态融合（`merge.ts`，118 行）

把 B站视频中的新闻条目并入 NewsItem：

```
URL 唯一标识：videoUrl#encodeURIComponent(newsTitle.slice(0, 60))
  - 同一视频同一标题 → 天然去重
  - 不同标题 → 各自独立 NewsItem
media 字段：[{kind: 'video', bvid, url, author, method, articleUrl, thumbnailUrl, durationSec}]
confidence：默认 'C'（B站来源置信度低）
relatedModels：不关联（噪声大，会污染模型关联表）
```

**关键决策**：B站条目**不关联** `relatedModels`，避免被视频噪声污染模型发现链路。
