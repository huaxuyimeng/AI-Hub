## 二、数据模型

```prisma
model DailyReport {
  id          String    @id @default(uuid())
  /// 北京日期（全局唯一，一天一份）
  date        String    @unique
  /// generating | ready | failed
  status      String    @default("generating")
  /// 结构化内容 JSON
  content     String?
  /// 主题：paper | ink | mint | lavender | amber | ocean
  theme       String    @default("paper")
  /// LLM 失败时降级版
  degraded    Boolean   @default(false)
  /// 失败原因
  error       String?
  /// 当前阶段（仅 generating 有意义）
  phase       String?    // collect | select | write | persist | done
  /// .pptx base64 缓存
  pptxBase64  String?
  /// 缓存生成时间
  pptxBuiltAt DateTime?
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt
  @@index([date])
}
```

## 三、生成管线（generate.ts，759 行）

### 3.1 两步 LLM 生成

```
Step 1: gpt-4o-mini 选题（4~6 条精选 + 理由）
  ↓
Step 2: gpt-4o-mini 成稿（要点文案 + 每条点评 + 趋势总结）
  ↓
zod 校验 → DailyReport.content（JSON）
  ↓
降级链：LLM 失败 → 重试 1 次 → 仍失败 → 无 AI 文案版
```

### 3.2 降级策略

| 场景 | 处理 |
|------|------|
| LLM 失败 × 1 | 自动重试（同一模型）|
| LLM 失败 × 2 | 降级版：原文摘要直出 + 数据页照常，`degraded = true` |
| 当日新闻 < 3 条 | 自动放宽到近 24h；仍不足则注明"今日收录较少" |
| 全部源失败 | 早报不生成，`status = 'none'` |

## 五、SlidePreview（1103 行）

**核心职责**：用 HTML/CSS 渲染 16:9 幻灯片预览，与 `build-pptx.ts` 共用同一套主题色板，确保预览与下载**所见即所得**。

**防溢出机制**：
- `cjkWidth()` 函数（中文 1.5em / ASCII 0.55em）
- `truncateOnce()` 避免双重截断（`…` 截断后再截一次变成`…`）
- `fit: 'shrink'` 自适应字号

## 六、tRPC 路由（server/router.ts，231 行）

| Procedure | 类型 | 说明 |
|-----------|------|------|
| `today` | `protectedProcedure.query` | 今日早报（含 phase 状态）|
| `list` | `protectedProcedure.query` | 历史早报列表 |
| `get` | `protectedProcedure.query` | 按日期获取单份早报 |
| `generate` | `protectedProcedure.mutation` | 手动触发生成（异步、幂等）|
| `regenerate` | `protectedProcedure.mutation` | 删除旧记录后重新生成 |
| `setTheme` | `protectedProcedure.mutation` | 换主题（自动清 pptx 缓存）|
| `delete` | `protectedProcedure.mutation` | 删除早报 |
| `download` | `protectedProcedure.query` | 下载 .pptx（含缓存命中逻辑）|

**异步生成**：立即返回当前 status，前端轮询 `today`；Vercel 中断时由次日 7:00 cron 兜底恢复。

**PPT 缓存**：面板只读元数据 + content，`pptxBase64` 在 `download` 时才读（节省内存）。

## 七、定时任务（两份 cron 代码）

### 7.1 Vercel Cron 入口（`src/app/api/cron/generate-daily-report/route.ts`，55 行）

```
vercel.json: "0 23 * * *"（UTC 23:00 = 北京 7:00）
  ↓
cron 路由：CRON_SECRET 鉴权 → withLock('cron:daily-report') → generateDailyReport()
```

### 7.2 模块内部 cron 工具（`src/features/daily-briefing/server/cron.ts`，96 行）

被 `generate-daily-report/route.ts` 调用，封装锁、幂等检查、失败重试一次。

**幂等保证**：`date` unique 约束 + 事务先查后建 + `withLock('cron:daily-report')`
