## 二、chat Router（chat.ts，181 行）

### 2.1 Procedure 一览

| Procedure | 类型 | 说明 |
|-----------|------|------|

| `trash` | `protectedProcedure` | 软删除对话 |
| `sendMessage` | `protectedProcedure` | 发送消息（核心）|

### 2.2 sendMessage 核心流程

```
用户发消息
  ↓ 1. 权限校验（conversation 属于本租户）
  ↓ 2. 用户消息落库（Message 表）
  ↓ 3. 取最新 50 条历史（MAX_HISTORY = 50，防止 context overflow）
  ↓ 4. 拉取用户对话风格（preferences）
  ↓ 5. buildSystemPrompt(prefs) → system prompt 字符串
  ↓ 6. 拼接 historyWithSystem（system 在首位，hist-A：仅内存不写DB）
  ↓ 7. chat(modelName, tenantId, historyWithSystem, opts) → AI 回复
  ↓ 8. AI 消息落库
  ↓ 9. 记录 UsageStat（仅真实调用；mock 跳过）
  ↓ 10. 更新 conversation.updatedAt
```

**关键代码**：`src/server/routers/chat.ts: sendMessage`

### 2.3 关键约束（hist-A 决策）

| 保险 | 做法 |
|------|------|
| MAX_HISTORY=50 | 超过 50 条时取最新的，避免 context overflow |
| system prompt 仅在内存 | `{ role: 'system', content: systemPrompt }` 拼在 history 数组首位，**不写 Message 表** |
| mock 模式不记账 | dev 模式 fallback 占位响应，**不记 UsageStat** |
| dev 日志 | dev 模式下打印 system prompt 长度（如 `[chat-style] injected system prompt (123 chars)`）|

### 2.4 错误处理（DS-02 安全约束）

```ts
try {
  const resp = await chat(modelName, ctx.tenantId, historyWithSystem, { temperature, maxTokens })
} catch (e) {
  if (process.env.NODE_ENV === 'production') {
    // 生产环境不可静默 fallback，必须显式报错
    throw new TRPCError({ code: 'INTERNAL_SERVER_ERROR', message: 'AI service unavailable' })
  }
  // dev 模式：返回占位响应（mock 模式不记账）
  aiText = `[dev-mode mock] AI 服务不可达：${sanitizeError(e.message)}...`
}
```

- **生产环境**：任何 chat 异常都抛 `TRPCError`，**不静默 fallback**
- **dev 环境**：返回 mock 响应 + sanitize 错误信息（防 provider URL/内部状态泄漏）
- **mock 模式不记 UsageStat**：避免估算值污染账本

### 2.5 Prisma Schema（Conversation / Message）

```prisma
model Conversation {
  id        String   @id @default(uuid())
  tenantId  String
  userId    String
  title     String   @default("新对话")
  ...
  messages  Message[]
  deletedAt DateTime?
}

model Message {
  id              String   @id @default(uuid())
  conversationId  String
  role            String   // 'user' | 'assistant' | 'system'
  content         String
  model           String?  // 字符串，不强制外键
  tokenCount      Int?     // assistant 消息的输出 token
  createdAt       DateTime @default(now())

  conversation    Conversation @relation(...)
}
```

```ts
export async function chat(
  model: string,           // e.g. 'deepseek-v4-flash'

  messages: ChatMessage[],
  options?: { temperature?, maxTokens?, devMock? }
```

### 3.2 三协议分发

```ts
// 1. resolveModelAlias(model) → 标准化模型名
// 2. getModel(name) → 拿 provider
// 3. getProviderAdapter(provider) → 适配器
// 4. 路由：
//    - OpenAI 兼容 → openai 包的 chat.completions.create
//    - Anthropic → @anthropic-ai/sdk 的 messages.create
//    - Gemini → @google/generative-ai 的 generateContent
// 5. resolveApiKey(tenantId, provider) → API key（DB 优先 / env 兜底）
// 6. 返回 { content, usage: { input, output } }
```

### 3.3 dev-mode mock

```ts
if (options.devMock !== false && process.env.NODE_ENV !== 'production') {
  const resolved = await resolveApiKey(tenantId, supported.provider)
  if (!resolved) {
    // 无 key → 返回 mock，不真正调用 provider
    return { content: mockResponse, usage: { input: 0, output: 0 } }
  }
```

## 四、System Prompt 构建（chat-style.ts，116 行）

### 4.1 6 个用户字段

| 字段 | 类型 | 默认值 | max |
|------|------|--------|-----|
| `chatPresetStyle` | enum | `friendly` | — |
| `chatOpeningLine` | string? | `null` | 500 字 |
| `chatPersonaRole` | string? | `null` | 500 字 |
| `chatCustomRules` | string | `""` | 2000 字 |
| `chatResponseLang` | enum | `auto` | — |
| `chatReasoningDepth` | enum | `normal` | — |

### 4.2 构建结果示例

```
输入：
  chatPresetStyle = "friendly"
  chatOpeningLine = "你好，我是你的专属 AI 助手"
  chatPersonaRole = "你是一个有 10 年经验的产品经理"
  chatResponseLang = "auto"
  chatReasoningDepth = "normal"

输出（system prompt 片段）：
你是一个友善、温和的助手。语气自然亲切，像和朋友聊天一样。
每次对话开始时，先用这句话打招呼：
"你好，我是你的专属 AI 助手"
你的角色：你是一个有 10 年经验的产品经理
Respond to all questions in English.
按常规方式回答问题，不需要刻意展示推理过程。
```

### 4.3 安全约束

- 所有字段有 max 长度限制（prompt 注入防御）
- `escapeForPrompt()` 转义用户输入特殊字符
- `MAX_TOTAL_PROMPT = 8000`（safety guard）
- 旧对话不重写 system prompt（新消息开始生效）
