## 4. P0 修复路线图（致命问题逐项）

### 4.1 SEC-F-01 — B 站 WBI md5 哈希

**风险**：md5 已不安全，B 站 API 完整性校验理论上可被碰撞。

**修复**（推荐方案 B，2h）：
```typescript
// src/lib/bilibili/wbi.ts
// 顶部加注释：
// SECURITY: WBI 签名是 B 站官方算法（md5 拼接 mixinKey）
// 此处仅适配 B 站接口，安全性由 B 站保证
// 禁止在项目其他位置使用 md5 做安全哈希（参见 SECURITY.md）
```

**验证**：检查 `git grep -n "createHash('md5')" src/` 仅命中此一处。

### 4.2 B-01 — chat.sendMessage 缺事务边界

**风险**：AI 调用失败时用户消息已落库但 `updatedAt` 未更新 → 对话列表时间戳不变 + UsageStat 可能缺失。

**修复**（核心改动，2h）：
```typescript
// src/server/routers/chat.ts:67-160
await prisma.$transaction(async (tx) => {
  const userMsg = await tx.message.create({ data: userMsgData });
  const aiMsg = await tx.message.create({ data: aiMsgData });
  await tx.conversation.update({ where: { id }, data: { updatedAt: new Date() } });
  return { userMsg, aiMsg };
});
// AI 调用放事务外（不涉及 DB）
```

**验证**：手动模拟 AI 失败 → 用户消息回滚 → 列表时间戳不变（已回滚到事务前状态）。

### 4.3 B-09 — 软删模型缺 unique 约束

**风险**：软删同名 Project / ApiKey 后可重建同名，DB 层无法拦截。

**修复**（schema 改动，1h + 迁移）：
```prisma
// prisma/schema.prisma
model Project {
  // ...
  @@unique([tenantId, slug])
}

model ApiKey {
  // ...
  @@unique([tenantId, provider, label])
}
```

**注意**：涉及 schema 变更 → 必须先告诉用户（参见 `00-clarify-before-act.mdc`）。

### 4.4 EH-F1 — cleanup-engine.ts 19 处空 catch

**风险**：清理结果 size 统计缺失，用户以为"清理了 X GB"实际更多或更少。

**修复**（批量改，1h）：
```typescript
// src/server/lib/cleanup-engine.ts — 全部 19 处
} catch (err) {
  logger.warn('[cleanup-engine] ${context}', {
    error: err instanceof Error ? err.message : String(err),
    // 必要上下文（path / dir / stage）
  });
  return <sensible-default>;
}
```

**验证**：`git grep -n "} catch {" src/server/lib/cleanup-engine.ts` 全部消失；构造 IO 错误场景手动跑清理。
