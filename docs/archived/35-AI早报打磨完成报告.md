## 二、🔴 阻塞性 bug 修复

### B1：BriefingToast 默认值反向（用户首登永远不弹）

**位置**：`src/components/daily-report/BriefingToast.tsx`
**问题**：`?? false` 与 schema `@default(true)` 矛盾，导致用户首次打开永远看不到弹窗
**修复**：`?? true`

### A3：查询错误无展示（面板只显示空状态）

**位置**：`src/components/daily-report/BriefingPanel.tsx`
**问题**：网络/服务器异常时 `todayQuery.isError` 永远不被渲染；用户只看到「尚未生成」，搞不清是数据问题还是功能坏了
**修复**：增加 `isError` 分支，展示错误信息 + 重试按钮；failed 状态用红色边框区分严重程度

### A4：PPT 下载每次重建（慢 + 爆 JSON 大小）

**位置**：`prisma/schema.prisma` + `src/server/routers/daily-report.ts`
**做法**：
- schema 加 `pptxBase64 String?` + `pptxBuiltAt DateTime?`（懒构建）
- `download` query：先查 cache 命中即返；未命中则构建 + 异步写库
- `setTheme` mutation：换主题时自动清缓存
- 返回 `{ base64, fileName, mimeType, cacheHit }`，前端显示「从缓存下载」或「文件已生成」

### A6：中文日期时区错位（Vercel 部署时）

**位置**：`src/lib/utils/parse-date.ts` + `src/lib/utils/time-utils.ts`
**问题**：`parseCnDateTime` 用 `new Date(y, m, d, h, mi)` 走机器本地时区；Vercel 是 UTC，导致中文源日期晚 8 小时、归到前一天
**修复**：默认按 UTC+8（北京时间）解释，用 `Date.UTC(...) - tzOffsetMs` 得到正确的 UTC 时间戳。经 grep 确认当前代码库中无任何调用，0 风险。

- BriefingPanel 生成中状态同上

## 四、🔵 健壮性收尾（C-full）

### C1：回填脚本（历史数据 briefingToast 为 null）

**位置**：`scripts/backfill-briefing-toast.ts`（新增）
**做法**：将所有 `briefingToast === null` 的 `UserPreferences` 记录补为 `true`；支持 `--dry-run` 先看影响行数
**用法**：
```bash
npx tsx scripts/backfill-briefing-toast.ts       # 执行
npx tsx scripts/backfill-briefing-toast.ts --dry-run  # 先看影响行数
```

### C2：enforceLimits 去重优化

**位置**：`src/lib/daily-report/types.ts`
**问题**：`truncate` 后字符串若含 `…`，再截一次会变成「文本……」
**修复**：新增 `truncateOnce` 辅助函数；若字符串已以 `…` 结尾且长度 ≤ max，直接返回

### C3：tryGenerate 注释补全

**位置**：`src/lib/daily-report/generate.ts`
**问题**：`picked` fallback 语义没注释，接手者看不懂为何用原序而非 LLM 选
**修复**：补注释解释「LLM ≥ 3 个索引 → 取 LLM 结果；否则按发布时间顺序取前 N 条（保证有内容）」

### C4：区分 generate / regenerate

**位置**：`src/server/routers/daily-report.ts`
**问题**：failed 状态点「重新生成」会覆盖旧记录，但 `generate` 本身不 delete，会产生语义歧义
**修复**：
- 新增 `regenerate` mutation：先 `deleteMany` + 再触发异步生成
- 面板 failed 状态绑定 `regenerate`（清旧 + 重做）
- `generate` 语义改为：幂等（已有 ready 直接返回）

### C5：none 状态完全不打扰

**位置**：`src/components/daily-report/BriefingToast.tsx`
**问题**：注释说「cron 7:00 跑之前不打扰」，代码里没实现——没有早报时也会触发弹窗
**修复**：`visible` 条件加 `status !== 'none'`，完全静默

### C6：结构化埋点字段

**位置**：`src/lib/daily-report/generate.ts` + `src/server/routers/daily-report.ts`
**做法**：
- `generateDailyReport` 开头记 `t0`，日志加 `duration` 字段
- `ready` 日志加 `{ date, degraded, items, duration }`
- `failed` 日志加 `{ date, error, phase, duration }`
- download router 加 `{ cacheHit, date, theme, duration }`
