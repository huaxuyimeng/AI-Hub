## 二、增量爬取实现

### 🔑 核心逻辑

系统已经实现了增量爬取，基于 `NewsItem.url` 唯一性：

```typescript
// service.ts saveItems()
await prisma.newsItem.upsert({
  where: { url: item.url },  // ← 唯一键
  update: { /* 更新已有 */ },
  create: { /* 新建 */ },
});
```

### 📦 数据流

```
RSS Feed → Parser → 去重（URL 唯一） → DB
                                  ↓
                          已是旧的？跳过
```

**保障**：
- ✅ 今天爬取只会读今天的新闻（RSS 只返回最新条目）
- ✅ 已存储的不会重复读取
- ✅ 已存储的不会重复创建
- ✅ 永久存储到 SQLite（数据库文件）

### 🔄 增量更新策略

当新抓取已存在的 URL 时：
- 只更新 `summary`、`relatedModels`、`companyTags`、`coverUrl` 等字段
- 保留原始 `createdAt`（首次入库时间）
- 保留原始 `publishedAt`（发布时间）

### 🔧 实现策略：混合匹配

```typescript
// sources.ts
export function extractCompanyTags(text: string): string[] {
  const lowerText = text.toLowerCase();
  const matched = new Set<string>();

  for (const company of AI_COMPANIES) {
    for (const alias of company.aliases) {
      if (lowerText.includes(alias.toLowerCase())) {
        matched.add(company.display);
        break;
      }
    }
  }

  return [...matched];
}
```

**当前实现**：纯正则匹配（免费、快速）  
**未来扩展**：可接入 LLM 补完复杂情况

## 四、封面图支持

### 🎯 提取策略（5级降级）

```typescript
function extractCoverUrl(itemBlock: string): string | null {
  // 1. media:content（标准 RSS 媒体扩展）
  const mediaContent = itemBlock.match(/<media:content[^>]+url=["']([^"']+)["']/i);
  if (mediaContent) return mediaContent[1];

  // 2. media:thumbnail（缩略图）
  const mediaThumb = itemBlock.match(/<media:thumbnail[^>]+url=["']([^"']+)["']/i);
  if (mediaThumb) return mediaThumb[1];

  // 3. enclosure（type 为图片）
  const enclosure = itemBlock.match(/<enclosure[^>]+type=["']image\/[^"']+["']/i);
  if (enclosure) return enclosure[1];

  // 4. content:encoded 中的 <img>
  const imgMatch = contentEncoded?.match(/<img[^>]+src=["']([^"']+)["']/i);
  if (imgMatch) return imgMatch[1];

  // 5. description 中的 <img>
  ...
}
```

**存储策略**：保留 CDN 链接（不下载到本地）
- ✅ 免费（不占存储）
- ✅ 快（不入库）
- ✅ 实时（图片更新自动同步）
- ⚠️ 依赖源站稳定性

### 📊 UI 展示

- 缩略图尺寸：112×80 px
- 失败兜底：`onError` 自动隐藏
