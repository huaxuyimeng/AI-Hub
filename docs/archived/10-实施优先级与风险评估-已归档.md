## 1. 决策矩阵

### 1.1 评估维度

| 维度 | 说明 |
|---|---|
| **影响力** | 1-5：对产品差异化 / 用户体验的影响 |
| **紧迫度** | 1-5：是否影响数据正确性 / 服务可用性 |
| **成本** | 1-5：实施所需工作量（5 = 最高） |
| **风险** | 1-5：失败概率 / 副作用（5 = 最高） |
| **依赖** | 列出 |

**优先级公式**（简化）：

```
优先级得分 = (影响力 + 紧迫度 × 2) / (成本 + 风险 × 1.5) + 依赖加成
```

## 6. 风险评估

### 6.1 技术风险

| 风险 | 概率 | 影响 | 缓解策略 |
|---|---|---|---|
| **yt-dlp 在 Vercel 不可用** | 中 | D-1 失败 | 用 yt-dlp-wrap npm 包 / 独立部署 |
| **B 站风控加剧** | 高 | D-1 降级 | 写入保护 + 多种 UP 主 / 文字版 |
| **AA API 不可访问** | 中 | P0-6 失败 | 退到静态表 + 每月人工更新 |
| **LiteLLM 价格滞后** | 低 | P0-5 准确度 | 官网验证（双源） |
| **LLM 解析成本失控** | 中 | 运营成本 | 用 gpt-4o-mini + 缓存 + 批量 |
| **并发抓取被 Vercel 限流** | 低 | cron 失败 | 限流 + 重试 + 错峰 |

### 6.2 产品风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| **关键词系统准确率下降** | 中 | 用户困惑 | 持续评估 + 快速回滚 |
| **意图搜索误解用户意图** | 高 | 用户体验差 | UI 实时预览 + 可修改 |
| **推荐系统推送用户不想看的** | 中 | 用户反感 | 显式反馈 + 渐进学习 |
| **B 站内容版权问题** | 低 | 法律风险 | 只索引摘要，不存储完整视频 |

### 6.3 运营风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| **数据源大量改版** | 高 | 抓取失败 | 源健康度监控 + 快速告警 |
| **AI 模型名频繁出新** | 中 | 关键词失效 | AI 抽取 + 每周评估 |
| **Cron 失败无人感知** | 高 | 数据陈旧 | 告警 + 监控仪表盘 |
| **LLM 厂商 API 限流** | 中 | 解析失败 | 多厂商 + 缓存 |

### 7.1 总览

| Phase | 工作量 | 预期收益 | ROI |

| **Phase 3**（D-4/5/7） | 2 周 | 深度差异化 + UI 创新 | ⭐⭐⭐ |
| **Phase 4**（D-6 + 规模化） | 2 周 | 个性化 + 工程化 | ⭐⭐⭐ |

### 7.2 关键 ROI 决策

**问题**：是否先做 D-1（B站 + 多模态）？

**答**：**先做 D-1**，因为：
- 用户感知最强（视频自动入库立刻可见）
- 与 ai-news-daily 形成代差（ai-news-daily 没跨模态）
- yt-dlp 已有范式可移植（详见报告 02 §2.F）
- 风险可控（写入保护兜底）

**问题**：是否先做 D-2/D-3（关键词 + 搜索）？

**答**：**与 D-1 并行**，因为：
- D-2/D-3 是 D-1 的"放大器"（关键词覆盖到视频标题）
- 投入低（LLM 便宜）
- 持续评估可控

**问题**：D-4（事件演变）是否要做？

**答**：**Phase 3 选做**，因为：
- 成本高（5 人天）
- 依赖事件抽取 LLM（准确率不稳定）
- **短期收益小**（用户还没用过不知道有没有用）
- 可以**Phase 5 用真实用户反馈决定**

**问题**：D-6（个性化）是否要做？

**答**：**Phase 4 做**，因为：
- 依赖大量行为数据（冷启动差）
- 推荐噪声大（容易推用户不关心的）
- **MVP 阶段：先用 UserPreferences 显式配置**

- ✅ 数据可信（P0 全部修完）
