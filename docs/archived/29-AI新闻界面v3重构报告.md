# AI 新闻界面 v3 全面 UI 重构报告

**实施时间**：2026-08-30  
**版本**：v3.0  
**参考 Skill**：Cursor Canvas SKILL + Cursor SDK UI Primitives  
**设计目标**：消除 AI 常见的低劣视觉风格（emoji、低劣渐变、彩虹色）

---

## 🎯 设计原则（Canvas Skill 启发）

### ❌ 禁止的"Slop Patterns"

| 模式 | 原因 |
|------|------|
| **渐变** | 视觉粗糙，破坏品牌一致性 |
| **Emoji 作为图标** | 不专业，跨平台不一致 |
| **Box-shadow** | 视觉杂乱，扁平化趋势不需要 |
| **彩虹色** | 缺乏视觉层次，重点不突出 |
| **装饰性边框** | 边框应结构性，非装饰 |
| **巨型文字** | 不必要的尺寸喧宾夺主 |

### ✅ 采用的设计语言

| 元素 | 处理 |
|------|------|
| **色彩** | 全部用 token 系统颜色（foreground / muted / accent）|
| **图标** | 纯文字或 SVG（无 emoji）|
| **边框** | 结构化 1px 边框（border-border）|
| **圆角** | rounded-md / rounded-lg（统一克制）|
| **层次** | H1 标题 → 关键指标 → 筛选 → 列表 |
| **间距** | 8 / 12 / 16 / 24 倍数系统 |

## 三、关键 UI 模式

### A. 关键指标条（顶部）

```tsx
<section className="grid grid-cols-2 gap-3 md:grid-cols-4">
  <StatCard label="总新闻数" value={1234} />
  <StatCard label="今日新增" value={56} accent="success" />
  <StatCard label="启用源" value={17} />
  <StatCard label="AI 厂家" value="40+" accent="info" />
</section>
```

**特点**：
- 数字用 `tabular-nums`（等宽数字）
- 标题用 uppercase + 0.18em 字距
- accent 状态用语义色（success = emerald，info = sky）

### B. 筛选区（分组布局）

```
┌────────────────────────────────────────────┐
│ 分类                                       │
│ [全部 1247] [AI Coding 423] [具身智能 189] │
│                                            │
│ AI 厂家                                    │
│ [OpenAI 234] [Google 198] [Anthropic 167]  │
│                                            │
│ [搜索框] [日期选择]                        │
└────────────────────────────────────────────┘
```

**特点**：
- 分类 + 厂家 + 搜索 三组并列
- 每个分组有小型 uppercase 标题
- 激活态用 fg 前景色，其他用 border 边框

### C. 新闻卡片（v3 简化）

```tsx
<article className="rounded-lg border border-border bg-card px-4 py-3">
  <div className="flex gap-3">
    {/* 封面图（可选） */}
    {coverUrl && <img className="h-20 w-28 rounded border" />}

    <div className="flex-1">
      {/* 标题 + 时间 */}
      {/* 摘要（line-clamp-2）*/}
      {/* 标签条（边框 + 文字） */}
    </div>
  </div>
</article>
```

**特点**：
- 无低劣渐变（hover 改 border 颜色）
- 标签统一为 border + bg-background（克制）
- 厂家标签可点击 → 触发筛选
- 跨源标识用纯文字"3 源"（无 emoji）

## 四、颜色系统（Token 化）

### 使用 Tailwind v4 Tokens

```css
/* 前景 / 背景 */
text-foreground          /* 主文字 */
text-muted-foreground    /* 次文字 */
bg-card                  /* 卡片背景 */
bg-background            /* 页面背景 */
bg-muted                 /* 弱背景 */

/* 边框 */
border-border            /* 默认边框 */
border-foreground/30     /* hover 边框（30% 不透明）*/

/* 强调色（语义化）*/
text-emerald-600         /* success */
text-sky-600             /* info */
text-amber-600           /* warning */
text-rose-600            /* danger */
```

### 不再用

```css
/* ❌ 蓝紫渐变 */
bg-gradient-to-r from-blue-500 to-purple-500

/* ❌ 彩虹色 */
style={{ background: ['#3b82f6', '#ef4444', '#10b981', ...] }}

/* ❌ Box-shadow */
shadow-lg shadow-blue-500/50

/* ❌ Emoji 图标 */
🔄 � 📈 🏢 🥧 ⭐ ✨ 🚀
```

## 七、Typography 排版

### 字号阶梯

```
H1:  28px / semibold / tight tracking   ← 主标题
H2:  20px / semibold                   ← 二级标题
H3:  14px / semibold / uppercase       ← 区块标题（uppercase）
body: 14px / normal                    ← 正文
small: 12px / normal                   ← 次要文字
tiny: 10px / normal / mono             ← 元数据 / 时间戳
```

### 字距

```
uppercase tracking-wider  → 0.05em（标准）
uppercase tracking-[0.18em] → 0.18em（强调）
```

## 八、交互细节

### 1. Hover 状态

```diff
- hover:shadow-lg hover:shadow-blue-500/30
+ hover:border-foreground/30 hover:bg-accent
```

**原则**：用边框/背景色变化，而非阴影。

### 2. 激活态

```tsx
// Pill 激活态
className={active
  ? 'bg-foreground font-medium text-background'
  : 'border border-border bg-background text-foreground/80 hover:bg-accent'}
```

### 3. 过渡动画

```tsx
className="transition-all"  // 200ms ease
```
