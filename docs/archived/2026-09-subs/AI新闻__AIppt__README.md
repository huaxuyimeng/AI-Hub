## 快速理解

### AIHub AI 早报 PPT 是什么？

一份每日自动生成的 **AI 新闻 PPT**，从采集到成品全链路：

```
RSS/API 采集（10 个信源）
    ↓
多因子选题（时效为主 + 多源印证 + 关注方向）
    ↓
LLM 改稿（要点 + 点评 + 趋势总结）
    ↓
pptxgenjs 渲染（6 套主题）
    ↓
用户下载 .pptx（原生 Office 格式，用户下载保存本地之后，可二次编辑）
```

### 核心数据（2026-08-29）

- 当日收录：216 条
- 信源：10 个（国产中文源 186 条 86% · 国际英文源 30 条 14%）
- 入选新闻：4~6 条（LLM 选题）
- PPT 页数：9~11 页（5 固定页 + N 条新闻 + 1 趋势 + 1 尾页）

### 市调结论（16 个主流工具）

所有竞品的 3 大高频投诉：
1. **导出失真**：预览完美，导出 PPTX 后字体/颜色/间距全乱
2. **模板同质化**：所有 AI PPT 看起来像同一个妈生的
3. **无溯源机制**：内容可信度无法判断，全黑盒

AIHub 的核心差异：真实数据驱动 + 信源透明 + 原生 .pptx 输出。

### 6 大记忆亮点（让人记住 AIHub）

| 亮点 | 说明 | 竞品有无 |
|---|---|---|
| 信源透明度页 | P3 独立页面展示置信度 A/B/C/D + 10 个信源贡献条数 | **无** |
| 置信度标签 | 每条新闻详情页右上角 chip（A 确证/B 高/C 中/D 存疑） | **无** |
| 每日动态副标题 | 封面底部 LLM 生成的一句话概括（不可预测但高度相关） | **无** |
| 数据趋势页 | 厂家提及 Top5 + 近 7 天柱图 + 分类分布 | 部分有 |
| AI 点评区 | 每条新闻底部 LLM 改写的一句话说明（"为什么这条重要"） | **无** |
| 一手来源链接 | 每条新闻附可点击 URL（防幻觉、防侵权） | **无** |
