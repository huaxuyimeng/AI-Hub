**问题**：原 RSS 地址 `/feed` 返回 HTTP 404

**解决方案**：
- 测试了多个常见 RSS 路径
- 发现正确地址为 `/rss`（不带扩展名）
- 验证结果：**30 条新闻**

**技术细节**：
```javascript
// 测试结果
fetch('https://www.geekpark.net/rss')
  .then(r => r.text())
  .then(xml => {
    const items = xml.match(/<item>[\s\S]*?<\/item>/gi);
    console.log(items.length); // 30
  });
```

**示例标题**：

- （其他 29 条...）

**修改内容**：
```diff
{
  name: '极客公园',
- url: 'https://www.geekpark.net/feed',
+ url: 'https://www.geekpark.net/rss',
  type: 'rss',
  priority: 8,
- enabled: false,
+ enabled: true, (默认)
- notes: '需要人工查找新 RSS 地址',
+ notes: '修复于 2026-08-30：正确地址为 /rss 而非 /feed',
}
```

### 2. The Verge AI

**问题**：专用 AI RSS `/ai-artificial-intelligence/rss/index.xml` 返回 HTTP 404

**调查发现**：
- 主 RSS `https://www.theverge.com/rss/index.xml` 仍可用（Atom 格式）
- 但包含所有分类，不限于 AI
- 专用 AI RSS 已停止提供

**解决方案**：
- 改用 **HTML 抓取**方式
- 目标页面：`https://www.theverge.com/ai-artificial-intelligence`
- 利用现有的 HTML 关键词白名单过滤

**技术细节**：
```javascript
// 页面验证
fetch('https://www.theverge.com/ai-artificial-intelligence')
  // 状态：200 OK
  // 页面大小：603 KB
  // 包含 272 个链接
  // AI 相关内容：丰富
```

**修改内容**：
```diff
{
  name: 'The Verge AI',
- url: 'https://www.theverge.com/ai-artificial-intelligence/rss/index.xml',
+ url: 'https://www.theverge.com/ai-artificial-intelligence',
- type: 'rss',
+ type: 'html',
  priority: 5,
- enabled: false,
+ enabled: true, (默认)
- notes: '可能已停止提供 RSS',
+ notes: '修复于 2026-08-30：专用 AI RSS 已失效，改用 HTML 抓取',
}
```

**优势**：
- ✅ 内容更新及时（直接从网页抓取）
- ✅ AI 专题页面内容质量高
- ✅ 已有 HTML 关键词白名单机制

## 💡 技术亮点

### 1. RSS 路径探测策略

```javascript
const urls = [
  'https://www.geekpark.net/rss',      // ✓ 成功
  'https://www.geekpark.net/feed',     // ✗ 原地址
  'https://www.geekpark.net/rss.xml',  // ✗
  'https://www.geekpark.net/atom.xml', // ✗
];
```

**经验**：常见路径为 `/rss`、`/feed`、`/atom.xml`、`/rss.xml`

### 2. HTML 降级策略

当 RSS 不可用时：
- 直接抓取 HTML 页面
- 利用现有的白名单关键词过滤
- 同站链接限制（避免噪声）

**优势**：
- 灵活性高
- 适用于任何网站
- 内容更新及时

### 3. 类型切换

```typescript
type: 'rss' → 'html'  // The Verge AI
```

系统自动根据 `type` 字段选择不同的抓取函数：
- `rss` → `fetchRss()`
- `html` → `fetchHtml()`
- `api` → `fetchApi()`
