## 🧠 核心能力

### 1. 自然语言 → 结构化意图（`parseSearchIntent`）

**LLM prompt 示例**：

```
查询: 性价比高的中文模型
→ LLM 返回：
{
  "query": "中文模型",
  "filters": {
    "provider": ["DeepSeek", "Alibaba", "Moonshot"],
    "origin": ["中国"],
    "minIntelligence": 70
  },
  "sort": "value-asc",
  "expandSynonyms": true
}
```

**支持的过滤维度**：
- `provider` — 厂商列表（OpenAI / Anthropic / DeepSeek / xAI / Meta / Mistral / Alibaba / Moonshot / MiniMax 等）
- `priceRange` — 输入/输出价格区间（USD/M tokens）
- `priceField` — input / output
- `minIntelligence` — 能力分 0-100
- `minSpeed` — 速度分
- `family` — 模型家族（claude / gpt / gemini）
- `origin` — 来源国家（中国 / 美国）

### 2. 结构化意图 → Prisma 查询（`executeIntentSearch`）

```typescript
// 示例意图 → Prisma where
const intent = {
  query: '中文模型',
  filters: {
    provider: ['DeepSeek', 'Alibaba'],
    minIntelligence: 70,
    origin: ['中国'],
  },
  sort: 'value-asc',
};

// Prisma where 构建：
{
  isActive: true,
  deletedAt: null,
  OR: [
    { name: { contains: '中文模型' } },
    { description: { contains: '中文模型' } },
    { externalId: { contains: '中文模型' } },
    { provider: { contains: 'deepseek' } },  // 大小写归一化
    { provider: { contains: 'alibaba' } },
  ],
  intelligence: { gte: 70 },
}
```

### 3. Provider → Origin 映射


**效果**：用户说"中文模型" → 自动过滤 DeepSeek / Alibaba / Moonshot / MiniMax / Qwen / 通义千问。

## 💡 设计取舍

### 1. 为什么用 debounce 800ms 而非实时？

- 每次输入都触发 LLM 调用，成本不可控
- 800ms 让用户有完整输入时间（如"GPT-4o"一次打完）
- 预览面板在用户停顿时自然出现，不打断输入流

### 2. 为什么 `intentSearchResult` 用联合类型而不是直接用 tRPC 返回值？

- tRPC 返回的 `models` 字段与 `RankingsTable` 的 `RankingRow` 接口有细微差异
- 统一在 UI 层做类型对齐，避免侵入 `intent-search.ts` 的纯函数设计

### 3. 为什么不在 `list` procedure 里直接集成意图搜索？

- 设计约束：不在现有 procedure 上叠加新功能，避免破坏 `list` 的稳定性
- 新功能独立 `search` procedure 调用，需要时引入，不需要时不影响现有流程

### 4. 为什么 Provider 过滤用 `contains` 而非 `in`？

- 用户可能输入"openai"（小写），但数据库存 "OpenAI"（首字母大写）
- `contains` + 小写归一化兼容大小写不一致的边界情况
- 精确匹配仍可通过 `provider` 下拉框（原有 `list`）完成

## 🚧 已知限制 / 后续优化

### 当前限制

| # | 限制 | 影响 | 优先级 |
|---|------|------|--------|
| 1 | LLM 调用有延迟（~1-2s）| 用户感知意图解析需要等待 | 🟡 中 |
| 2 | Provider→Origin 映射需手动维护 | 新厂商加入时需同步更新 | 🟡 中 |
| 3 | 价格过滤只支持区间，不支持「比某模型便宜」| 自然语言表述不统一 | 🟢 低 |
| 4 | 无搜索历史 / 推荐查询提示 | 首次用户不知道能搜什么 | 🟢 低 |

| 2 | 搜索历史（localStorage 存最近 5 条）| 中（提升回访体验）| 1h |
