## 二、3.2 chat page 首次引导浮窗

### 改动文件
`src/app/(app)/chat/page.tsx`

### 行为
1. 进 chat 页 → 800ms 后弹出 onboarding 浮窗（如果 `chatStyleOnboarded = false`）
2. 浮窗内容：介绍 5 预设风格 + 角色 / 开场白 / 规则 / 引导用户去「设置 → 对话风格」
3. **"知道了"**：写 DB `chatStyleOnboarded = true`（跨设备同步）
4. **"稍后再说"**：只关闭，下次还会出现
5. 已 onboarded 用户不再弹

### 关键点
- 用 `trpc.preferences.getChatStyle` 获取 onboarded 字段（**不写 localStorage**，保证多设备）
- `trpc.preferences.updateChatStyle.useMutation` 设 `chatStyleOnboarded: true`
- 浮窗样式：mask + 居中卡片 + 阴影（z-50）
