## 三、清理缓存功能（Phase 4 设计）

### 3.1 核心原则

**只清理可重建的临时产物，绝不删除用户内容（新闻、对话、收藏、早报正文）**。

### 3.2 UI 设计（设置页新增第 11 个 tab：「数据与缓存」）

```
┌──────────────────────────────────────────────────────────┐
│  📦 数据与缓存                                            │
│                                                            │
│  💡 清理缓存只删除可重建的临时产物，不会影响你的           │
│     新闻、对话、模型信息、早报正文等任何内容数据。          │
├──────────────────────────────────────────────────────────┤
│  ① PPT 早报缓存（pptxBase64，可重建）           12.4 MB    │
│     一周内 7 份 · 锁定 1 份 · 可清理 22 份                │
│     策略：自动清理一周前的；锁定的永不清理                  │
│     [📋 查看锁定列表]  [🔧 批量锁定/解锁]  [🧹 立即清理] │
├──────────────────────────────────────────────────────────┤
│  ② 模型价格快照（可重建）                       0.5 MB    │
│     共 156 条 · 每个模型保留最新 3 个                     │
│     [🧹 立即清理]                                          │
├──────────────────────────────────────────────────────────┤
│  ③ R2 孤儿文件（已上传但未被引用）               0 个      │
│     R2 未配置 / 当前无孤儿                                  │
│     [🧹 立即扫描清理]                                      │
├──────────────────────────────────────────────────────────┤
│  ④ 自动清理日志（最近 5 次）                              │
│     2026-09-02 03:00  新闻清理 - 12 条                    │
│     2026-09-02 03:00  B站缓存清理 - 0 条                   │
│     2026-09-01 03:00  孤儿文件 - 3 个                      │
└──────────────────────────────────────────────────────────┘
```

### 3.3 3 项关键决策（清理缓存子模块）

| # | 决策 | 选项 | 含义 |
|---|---|---|---|
| cache-1 | 范围 | scope-A（仅后端 DB 缓存） | 不清前端 localStorage / tRPC cache |
| cache-7 | 锁定 UI | lock-ui-B（双入口） | 「数据与缓存」tab + 早报面板都加 🔒 按钮 |
| cache-8 | 确认策略 | confirm-A（仅 PPT/快照/R2 三项需确认） | 其他清理直接 toast |
| cache-9 | 日志 | log-B（localStorage + Upstash） | cron 自动清理 → Upstash；手动清理 → localStorage |

### 3.4 文件改动

| 文件 | 改动 |
|---|---|
| `prisma/schema.prisma` | `DailyReport` 新增 `locked Boolean @default(false)` |
| `src/server/routers/cache.ts` | **新建**：3 procedure（stats / cleanPptCache / cleanSnapshots / scanOrphanR2 / setLocked） |
| `src/server/routers/_app.ts` | 挂载 `cacheRouter` |
| `src/app/(app)/settings/page.tsx` | 加「数据与缓存」section + 第 11 个 tab |
| `src/features/daily-briefing/components/BriefingPanel.tsx` | 加 🔒 切换按钮 |
| `src/lib/cleanup.ts` | 加日志写入 Upstash Redis |
| `src/lib/cleanup-db.ts` | 调用 cleanup logger |

### 3.5 安全约束

- 所有清理操作必须在事务内执行
- PPT 锁定是 **永久的**（用户必须主动解锁）
- 清理失败不影响其他清理项（continue on error）
- 清理日志保留最近 50 条（Upstash）
