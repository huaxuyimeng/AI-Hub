## 一、TL;DR（一页纸摘要）

**AIHub 是一个面向开发者的 AI 工具聚合工作台**，定位"工作台 = 对话 + 项目分析 + AI 新闻 + 模型排行"，由单一团队同时推进四象限。**当前已超出 MVP 标准**——不仅完成了核心闭环，还在差异化功能（AI 新闻 PPT 早报 / B 站爬虫 / 关键词系统 / 意图搜索）上完成度很高。

但**项目目前**：

- ✅ **基本盘稳**：多租户隔离 / 安全防护 / 性能 / 数据正确性 4 个 P0 维度全绿
- ⚠️ **关键缺口**：用户**自助配置 AI Key** 这个核心痛点未解决（用户每次新增功能都要后端改 env）
- ⚠️ **UI 一致性**：P2 层级 42 个问题待收敛，部分模块（项目分析）仍含假数据
- ⚠️ **运营断点**：ToB 卖商业版 / ToC 走社区版的两条路径尚未分叉

**建议**：本季度聚焦"**让用户自己玩起来**"（API Key 自助化 + AI 对话个性化），下季度走"**让功能组合玩起来**"（跨模块组合 + 团队协作）。

## 二、项目定位与目标用户

### 2.1 一句话定位

> 一个让开发者用 AI 提升代码质量的 Web 工作台，支持多模型对比和插件扩展。

### 2.2 目标用户（按优先级）

| 优先级 | 用户群 | 核心痛点 | 现有满足度 |
|---|---|---|---|
| 🥇 **P0** | 全栈独立开发者 | 一个统一界面访问多种 AI 工具 | ✅ 80% |
| 🥈 **P1** | AI 资讯重度阅读者 | 不让 AI 新闻淹没在噪音里 | ✅ 90% |
| 🥉 **P2** | 模型对比研究者 | 跨厂商模型表现 + 价格透明 | ✅ 75% |
| 🎖️ P3 | 小型研发团队 | 团队内统一 AI 模型策略、共享知识库 | ⚠️ 20% |

### 2.3 竞品对照（粗略）

| 竞品 | 重叠模块 | AIHub 差异点 |
|---|---|---|
| **ChatGPT** | 对话 | AIHub 多模型 + 项目上下文 + 新闻聚合 |
| **Cursor / Trae** | 代码检错 | AIHub 走工作台聚合而非 IDE 嵌入 |
| **橘鸦 AI 早报** | AI 资讯 + PPT | AIHub 内嵌生成 vs 外部分享 |
| **LMArena / Artificial Analysis** | 模型排行 | AIHub 含价格 + 中文源 |
| **Notion AI** | 工作台 | AIHub 更聚焦开发者场景 |

## 四、用户痛点与产品决策

### 4.1 当前最大用户痛点（按频度/严重度排序）

| # | 痛点 | 影响范围 | 解决方案 | 优先级 |
|---|---|---|---|---|
| 1 | **每个 AI 功能要单独配 Key，后端运维负担重** | 所有付费功能 | AI Key 自助库（Provider 维度） | 🔴 P0 |
| 2 | **AI 对话无个性化（无开场白 / 风格 / 角色）** | 全部对话用户 | 对话风格配置（6 字段） | 🔴 P0 |
| 3 | **设置页二级导航冗余** | 所有用户 | 顶部水平 tab | 🟠 P1 |
| 4 | **新用户不知道能配哪些 AI Key** | 新注册用户 | 设置页「AI 模型 Key」section | 🟠 P1 |
| 5 | **代码分析仍用假数据（SEED_FILES）** | 项目页用户 | 与产品决策：保留 demo / 接真实文件 | 🟡 决策 |
| 6 | **插件系统业务插件 0 个** | 开发者 | 写示例插件 + 文档 | 🟡 P2 |
| 7 | **移动端体验差（无 hamburger / drawer）** | 移动端用户 | 响应式重构 | 🟡 P2 |
| 8 | **无国际化（中文硬编码）** | 海外用户 | i18n 基础 | 🟡 P3 |

### 4.2 已做出的产品决策

| 决策点 | 决定 | 理由 |
|---|---|---|
| **Key 维度** | 按 Provider 分，跨功能共享 | 12 Provider 覆盖主流模型，避免 N×M 矩阵 |
| **Key 默认值** | DeepSeek V4 Flash + GLM-4-7-Flash | 性价比最高，开箱可用 |
| **无 Key 时降级** | UI 弹窗让用户手动选 | 不静默失败，体验一致 |
| **对话风格引导** | 首次进入聊天页浮窗 | 不阻塞，3 秒自消失 |
| **设置页导航** | 顶部水平 tab | 复用现有视觉层级，桌面端更舒展 |
| **REST API Key 保留** | 单独 tab | 不影响现有用户 |

## 五、Roadmap 建议

### 5.1 本季度（Q3 2026，9-10 月）：让用户自己玩起来

**核心主题**：**赋能用户配置 + 个性化体验**

| 里程碑 | 交付物 | 估时 | 验收标准 |
|---|---|---|---|
| **M1：AI Key 自助库** | 12 Provider 适配器 + UI + 测试连接 | 2 周 | 用户能在设置页添加 / 测试 / 删除任意 Provider 的 Key |
| **M2：AI 对话风格系统** | 6 字段配置 + 注入 prompt + 首次引导 | 1 周 | 用户可定制开场白 / 风格 / 角色，prompt 实时预览 |
| **M3：设置页重构** | 顶部水平 tab + 移动端 select | 0.5 周 | 桌面端 10 tab 横排，移动端 select |
| **M4：CI 基础** | GitHub Actions 跑 tsc + usage test | 0.5 周 | PR 自动检查 TS error |

**Q3 总估时**：4 周 · 单人 / 双人

### 5.2 下季度（Q4 2026，11-12 月）：让功能组合玩起来

**核心主题**：**跨模块组合 + 团队协作**

| 里程碑 | 交付物 | 价值 |
|---|---|---|
| **M5：跨模块组合** | 「AI 资讯 → 对话」一键问 / 「项目文件 → 分析 → 对话」 | 用户工作流串联 |
| **M6：团队协作 v1** | 邀请码 + 成员列表 + 共享 API Key 池 | ToB 切入点 |
| **M7：插件示例** | 1-2 个真实业务插件（例：Markdown 转 PPT） | 生态启动 |
| **M8：移动端体验** | hamburger + drawer + 关键页响应式 | 移动端可达性 |

### 5.3 半年后（Q1-Q2 2027）：商业化

| 维度 | 计划 |
|---|---|
| **付费墙** | Team 版 ¥29/人/月：共享 Key 池 + 团队模板 + 高级分析 |
| **免费版限制** | 个人对话 100 次/月 + 新闻无 B 站 + 项目分析 3 次/月 |
| **数据指标** | DAU / 留存 / 付费转化 / 单用户 LTV |
| **风险预案** | 付费转化 < 1% → 收紧免费额度；团队采用 > 5% → 加速 ToB 投入 |

## 六、风险评估

### 6.1 技术风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| **LiteLLM 网关挂掉** | 中 | 高（全部 AI 功能停摆） | 多 Provider 化（已规划）+ 降级 UI |
| **Vercel 冷启动 + Cron 限频** | 中 | 中（爬虫遗漏） | 分布式锁 + 指数退避（已实施） |
| **R2 公开 endpoint 泄露** | 低 | 高（用户数据暴露） | 路径穿越防护已加 + 月度安全 audit |
| **Prisma SQLite 静默吞并发** | 中 | 中（数据丢失） | P1 已识别，下季度转 PostgreSQL |
| **第三方 RSS 源失效** | 高 | 中（新闻缺源） | 健康度监控 + 自动降级 |

### 6.2 产品风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| **付费转化 < 1%** | 中 | 高（商业模式失败） | 缩短 Q4 反馈循环；提供免费额度上限 |
| **竞品快速跟进**（如 Cursor 加新闻模块） | 高 | 中（差异化被削弱） | 加速差异化（PPT 早报 / 跨模态融合） |
| **大厂免费压制**（豆包 / Kimi 全免费） | 中 | 中（C 端价格战） | 走 ToB + 垂直场景 |
| **AI 内容合规**（生成 PPT 涉及版权） | 低 | 高（下架风险） | 内容溯源 + 用户协议 + 申诉通道 |

### 6.3 团队 / 运营风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| **单人开发瓶颈** | 高 | 高（速度下降） | 招 1-2 名全职 / 拆分 owner |
| **社区冷启动** | 中 | 中（PMF 验证难） | Q4 推 1 个示例插件 + 1 篇技术博客 |
| **文档腐化** | 中 | 中（新成员上手难） | 季度文档审计 + 自动化 link check |
