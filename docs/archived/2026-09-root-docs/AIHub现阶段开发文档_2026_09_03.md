## 一、项目概览

AIHub 是一个**多租户 AI 信息聚合与使用平台**（毕业设计 MVP），一句话定位：

> 把「AI 新闻情报、模型性价比排行、B 站生态动态、AI 早报」聚合成一站式工作台，并为每个租户提供 AI 对话、用量计费、项目代码审查等自有 AI 能力。

当前形态：19 个路由全部编译通过（build.log），首屏 JS 87–157 kB，已配置 Vercel 5 条 cron 定时任务，处于「核心功能闭环完成、生产化打磨中」阶段。

## 二、做了什么（功能清单）

### 1. 基础平台层
- **认证**：NextAuth 双通道——GitHub OAuth + 邮箱密码（bcryptjs），JWT session 携带 tenantId/role；注册接口带 Upstash 限流
- **多租户**：`createTenantPrisma()` 用 Prisma `$extends` 中间件对白名单模型在查询层强制注入 `tenantId + deletedAt: null`，业务代码无感隔离
- **软删除**：User/Project/ApiKey/Conversation/Score/InstalledPlugin/PluginAuditLog/UsageStat 等 9 个模型支持软删 + 恢复 + 事务化硬删（lifecycle）
- **项目与文件管理**：项目 CRUD、项目文件挂 R2 对象存储（懒初始化 + 魔数校验）、REST API Key 管理
- **OAuth 跨租户撞库防护**：同邮箱跨租户 OAuth 登录显式拦截

### 2. AI 对话与路由（src/lib/ai）
- **12 个厂商适配器**（OpenAI/Anthropic/Gemini/DeepSeek 等，6 真 6 占位），按 OpenAI/Anthropic/Gemini 三协议分发（router.ts）
- **Key 三级解析**（key-resolver）：租户自配 Key（密文可解）→ 平台 env Key 兜底 → 报错；模型白名单 + 别名归一
- **对话体验**：历史裁剪（最新 50 条）、用户风格 system prompt 注入（chatPresetStyle/chatOpeningLine）、温度/maxTokens 可调
- **用量记账**：sendMessage 全链路 recordUsage，token + 费用落库

### 3. 用量计费（src/lib/usage.ts）
- 当日用量聚合：复合唯一键 upsert + Prisma P2002 冲突重试，解决并发写竞态
- 30 天用量/费用统计、按模型拆分、按实时价格表重算成本

### 4. 代码审查（analysis router）
- AI 输出 JSON 解析 → 事务批量写 file/issue/score，消除 N+1

### 5. 新闻聚合（src/lib/news）— 体量最大的模块
- **多源抓取**：RSSHub、B 站资讯、微信公众号格式探测（8 个 parser）
- **去重**：实体指纹（替代 Jaccard 相似度），支持多源交叉验证
- **分类**：AI 相关性判定（关键词正则 + LLM 兜底）
- **搜索**：术语词典 + 同义词展开检索；「智能意图搜索」用 LLM 解析意图、失败自动降级字面搜索
- **日期诚信**：多级回退算法，「绝不用抓取时间冒充发布时间」
- **源健康度监控**：/api/news/health 公开端点

### 6. 模型性价比排行（src/lib/rankings）
- **算法**（algorithm.ts，13 个单测全过）：混合价 + 能力变换 + **帕累托前沿**识别
- **混合爬虫**：PRICING_TABLE 内置表 → 厂商官网 → 手动兜底，信号量限流
- **自动发现**：从近 7 天新闻标题提取新模型名
- **UI**：Top3 领奖台 + 帕累托散点 + 价格快照走势 + 模型详情页关联新闻

### 7. B 站生态（src/lib/bilibili）
- **wbi 签名**：官方签名算法 1:1 TypeScript 翻译 + mixin key 缓存
- **风控对抗**：指数退避、登录态 cookie、请求间隔节流
- **写保护**：逐 UP 主合并策略，抓取失败不覆盖已有数据
- 字幕抓取（SSRF 域名白名单防护）

### 8. AI 早报日报（src/features/daily-briefing + src/lib/slide-engine）
- **slide-engine 渲染管线**：zod 契约 → 布局测量（失败降级）→ QA lint gate → pptxgenjs 渲染 PPTX / web 双输出
- 每日 23:00 Vercel cron 自动生成，支持主题切换、下载、生成状态轮询

### 9. 前端工作台（src/app + src/components）
- **9 大页面**：workbench 仪表盘、projects、chat、usage、news（新闻/B站双 Tab + AI 早报）、rankings、plugins、cleanup、settings（8 个 section）
- **主题系统**：6 套 OKLCH 预设 + HSL 自定义强调色 + R2 壁纸；`bootstrap-script.ts` 内联预绘制防 FOUC；MutationObserver 联动暗色渐变
- **⌘K 命令面板**：focus trap + IME isComposing 处理
- **tRPC 端到端类型安全** + React Query 成熟用法（placeholderData 防闪烁、按状态动态轮询、精细化 invalidate）

### 10. 运维与脚本层
- **Vercel cron × 5**：新闻 3h / 模型排行每日 / 术语每周日 / 日报每日 23 点 / B 站 6h，与本地脚本同入口复用
- **观测**：结构化 JSON logger + Slack 告警 + 文件锁（尽力而为的并发防护）
- **35 个脚本**分为五类：数据回填修补（9）、爬虫调试（13）、术语运营流水线 extract→expand→review→evaluate（4+）、诊断验收（8）、同步（1）
- **docs/ 46 份编号实施报告**：从 P0 修复 → 分布式锁 → B 站爬虫 → slide-engine，脉络完整可追溯

## 四、亮点

1. **租户隔离做成中间件而非纪律**——`$extends` 在 Prisma 查询层强制注入租户过滤，业务代码想漏都难；配合越权探测防护（资源不属于你时返回 NOT_FOUND 而非 FORBIDDEN，不泄露资源存在性）
2. **并发竞态的正经解法**——UsageStat 复合唯一键 upsert + P2002 冲突重试，而不是「先查再写」的侥幸写法
3. **Key 安全双存设计**——sha256 hash（校验）+ AES-256-GCM 密文（可解密使用）分离存储，明文只在创建时一次性返回
4. **性价比算法有数学骨架**——混合价归一 + 能力变换 + 帕累托前沿识别「没有更便宜且更强」的模型集合，且 13 个单测护航，是答辩级亮点
5. **数据诚信意识**——新闻日期多级回退算法拒绝用抓取时间冒充发布时间；实体指纹去重 + 多源交叉验证替代朴素相似度
6. **反爬对抗工程化**——B 站 wbi 签名逐行对齐官方算法、指数退避、逐 UP 写保护（抓挂了不丢旧数据）
7. **slide-engine 是「编译器式」设计**——zod 契约 → 布局规划 → QA lint gate → 双端渲染，把 PPT 生成做成可测试管线而非字符串拼接
8. **错误处理规范**——sanitizeError 正则分级脱敏、zod 全量输入校验、env fail-fast（zod 校验启动配置）
9. **升级前瞻**——next.config.js 运行时识别 Next 14/15 自动切换配置字段，为升级铺路
10. **文档驱动的开发过程**——46 份编号实施报告 + 代码内 H-xx/C-xx/S-xx 修复痕迹编号，过程可追溯

## 五、解决了什么痛点

| 用户痛点 | AIHub 的解法 |
|---|---|
| AI 信息源太散（新闻/榜单/B站/公众号各自为政） | 新闻聚合 + B 站生态 + 模型排行 + AI 早报四合一，单一工作台 |
| 模型太多不知道选哪个、价格不透明 | 性价比算法 + 帕累托前沿 + 价格快照走势，把「选型」变成看图决策 |
| 每天人工翻情报费时 | cron 全自动：3h 新闻、每日 23:00 早报 PPT，打开即读 |
| 多平台 API Key 管理乱、账单黑盒 | 租户自带 Key（密文托管）+ 当日聚合用量计费 + 按模型费用拆分 |
| 团队共用 AI 时数据互窜、删除不放心 | 多租户中间件强制隔离 + 软删/恢复/事务硬删三件套 |
| 爬虫易被风控、数据抓挂就丢 | wbi 签名 + 指数退避 + 写保护合并，失败降级不覆盖 |
| 通用 PPT 工具做不出日报 | 契约驱动的 slide-engine 专机专用，QA gate 保证排版不崩 |
