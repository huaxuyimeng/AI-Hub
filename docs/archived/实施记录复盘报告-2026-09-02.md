## 二、未闭环 / 存在风险的事项（**6 项**）

### 🔴 P0 — 必须尽快闭环

#### P0-1：D-2 智能搜索"验证锁"——`TermDictionary` 已建但 `verified=true` 为 0

**证据**（出自 28b）：
- `scripts/extract-terms.ts` / `expand-synonyms.ts` / `review-terms.ts` / `evaluate-terms.ts` 4 个脚本全部就绪
- 周日 cron `/api/cron/refresh-terms` 就绪
- **但 `TermDictionary` 表里 `verified=true` 数量 = 0** → 智能搜索全部走"字面回退"，功能空转

**为何没闭环**（出自 33 §2）：
- `review-terms.ts` 是 **readline 交互式脚本**（a/d/e/s），AI Agent 无法替代人工拍板
- 这是 **设计上的安全锁**（防 LLM 幻觉术语污染），不应自动 `verified`，**保留安全锁**

**行动**（必须用户介入，全套清单）：
```bash
1. 启动 LiteLLM（或设置 LITELLM_BASE_URL 指向远程 proxy）
2. npx tsx scripts/extract-terms.ts        # 抽取新词
3. npx tsx scripts/expand-synonyms.ts      # 补同义词
4. npx tsx scripts/review-terms.ts         # ← 必须人工：a 通过 / d 删除 / e 编辑
5. npx tsx scripts/evaluate-terms.ts       # 评估 precision（目标 ≥ 0.75）
```
**建议**：首批审核 20~30 个高频模型名（GPT-5.x / Claude Fable / DeepSeek V4 / Gemini 3.5…），半天可完成。

#### P0-2：D-3 意图搜索仅服务"模型排行"，**新闻版还没上**

**证据**（出自 33 §1 + 实际代码核对）：
- `src/lib/news/intent-search.ts` 文档明确"仅用于 Model"
- 用户在新闻页搜"具身智能最近一周""OpenAI 和 Anthropic 吵架相关"时，**只能走关键词匹配**，不理解时间范围 / 分类 / 公司组合
