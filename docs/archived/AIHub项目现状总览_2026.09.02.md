## 一、一句话定位

**AIHub = 开发者专属 AI 工作台**，在一个统一界面集成：

1. **💬 多模型对话**（DeepSeek / GLM / OpenAI / Claude / Gemini / Ollama…）
2. **📁 项目代码 AI 检错**（5 维评分）
3. **📰 AI 资讯聚合 + 每日 PPT 早报**
4. **🏆 模型排行 + 价格预警**
5. **🔌 插件系统**（沙箱化扩展）

## 三、用户群与场景

### 3.1 主要用户群

1. **🥇 全栈独立开发者**——一站式 AI 工具
2. **🥈 AI 资讯重度阅读者**——聚合 + PPT 早报
3. **🥉 模型对比研究者**——价格 + 能力 + 中文源

### 3.2 典型场景

| 场景 | 当前流程 |
|---|---|
| **写代码时用 AI 辅助** | 打开对话 → 选模型 → 写代码 → 看到价格 |
| **AI 早会前看资讯** | 打开新闻页 → 看 PPT 早报 → 一键下载分享 |
| **选新模型前查价格** | 打开排行 → 对比多源定价 → 关注模型 → 价格预警 |
| **分析项目代码** | 上传项目 → 跑 AI 检错 → 看 5 维评分 → 追问细节 |
