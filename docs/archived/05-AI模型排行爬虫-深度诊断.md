#### 方案 A：真抓官网（彻底）

每个厂商的定价页结构都不一样，需要独立解析器。**MVP 阶段建议从 2-3 个最重要的开始**：

```ts
// src/lib/rankings/scrapers/openai.ts
// 来源：https://openai.com/api/pricing/
export async function scrapeOpenAIPricing(): Promise<Map<string, { input: number; output: number }>> {
  const res = await fetch('https://openai.com/api/pricing/', {
    headers: { 'User-Agent': 'Mozilla/5.0 (compatible; AIHub-Bot)' },
    signal: AbortSignal.timeout(15_000),
  })
  if (!res.ok) throw new Error(`HTTP ${res.status}`)
  const html = await res.text()

  const result = new Map<string, { input: number; output: number }>()
  // 解析策略：每行 <tr> 包含模型名 + 输入价 + 输出价
  // 注意 OpenAI 改版频繁，解析器要柔性
  const rowRe = /<tr[^>]*>([\s\S]*?)<\/tr>/g
  let m
  while ((m = rowRe.exec(html)) !== null) {
    const row = m[1]
    const cells = [...row.matchAll(/<td[^>]*>([\s\S]*?)<\/td>/g)].map(c => cleanText(c[1]))
    if (cells.length < 3) continue
    const modelName = cells[0]
    const inputPrice = parsePrice(cells[1])
    const outputPrice = parsePrice(cells[2])
    if (modelName && inputPrice !== null && outputPrice !== null) {
      const externalId = normalizeModelId(modelName)
      result.set(externalId, { input: inputPrice, output: outputPrice })
    }
  }
  return result
}

function parsePrice(s: string): number | null {
  // "$2.50 / 1M tokens" → 2.50
  const m = s.match(/\$?\s*(\d+(?:\.\d+)?)/)
  return m ? parseFloat(m[1]) : null
}

function normalizeModelId(s: string): string {
  return s.toLowerCase()
    .replace(/\s+/g, '-')
    .replace(/[^\w-]/g, '')
}
```

**注意**：
- OpenAI/Anthropic 等的定价页**经常改版**（AiNews 真接起来每月要修一次）
- **必须加金标准快照测试**（详见报告 08 §3）
- 解析失败的厂商**降级到静态表**，而不是阻塞其他源

#### 方案 B：接 LiteLLM（推荐 + 简单）

LiteLLM 本身有 `/v1/model/info` 端点暴露**模型列表 + 价格 + 元数据**。aihub 已经在用 LiteLLM 路由（`src/lib/ai/client.ts`），**直接复用**：

```ts
// src/lib/rankings/scrapers/litellm.ts
export async function scrapeLiteLLM(): Promise<Map<string, ModelInfo>> {
  const baseURL = process.env.LITELLM_BASE_URL ?? 'http://localhost:4000/v1'
  const res = await fetch(`${baseURL}/model/info`, {
    headers: {
      'Authorization': `Bearer ${process.env.LITELLM_API_KEY ?? 'anything'}`,
    },
    signal: AbortSignal.timeout(10_000),
  })
  if (!res.ok) throw new Error(`HTTP ${res.status}`)
  const data = await res.json() as { data: Array<LiteLLMModelInfo> }

  const result = new Map<string, ModelInfo>()
  for (const m of data.data) {
    const inputCost = m.litellm_params?.input_cost_per_token ?? 0
    const outputCost = m.litellm_params?.output_cost_per_token ?? 0
    // LiteLLM 报价是 per token，转 per million
    const inputPerM = inputCost * 1_000_000
    const outputPerM = outputCost * 1_000_000
    result.set(m.model_name, {
      input: inputPerM,
      output: outputPerM,
      maxTokens: m.litellm_params?.max_tokens,
      maxInputTokens: m.litellm_params?.max_input_tokens,
    })
  }
  return result
}

interface ModelInfo {
  input: number
  output: number
  maxTokens?: number
  maxInputTokens?: number
}
```

**好处**：
- LiteLLM 本身已统一所有模型（OpenAI/Anthropic/Bedrock/Vertex）
- 不需要为每个厂商写解析器
- 价格 = LiteLLM 路由实际收的钱（**最准确**）

**坏处**：
- 依赖 LiteLLM 部署（README §边界里说 MVP 没有 docker-compose）
- LiteLLM 价格可能滞后于官方

async refreshAll(): Promise<{ total: number; succeeded: number; failed: number; details: Array<{ id: string; status: 'ok' | 'failed'; error?: string }> }> {
  const models = await prisma.model.findMany({ where: { isActive: true } })
  const results = await Promise.allSettled(models.map(m => this.refreshOne(m.id)))
  const details = results.map((r, i) => {
    if (r.status === 'fulfilled') return { id: models[i].id, status: 'ok' as const }
    return { id: models[i].id, status: 'failed' as const, error: String(r.reason) }
  })
  return {
    total: models.length,
    succeeded: results.filter(r => r.status === 'fulfilled').length,
    failed: results.filter(r => r.status === 'rejected').length,
    details,
  }
}

```ts
async discoverFromNews(): Promise<string[]> {
  // 1. 查最近 7 天新闻标题
  const recentNews = await prisma.newsItem.findMany({
    where: {
      deletedAt: null,
      publishedAt: { gte: new Date(Date.now() - 7 * 24 * 60 * 60 * 1000) },
    },
    select: { id: true, title: true, summary: true },  // ← 不依赖 relatedModels
    orderBy: { publishedAt: 'desc' },
    take: 500,  // 限制最多看 500 条
  })

  // 2. 直接用 extractModelNames 提取
  const mentionedModels = new Set<string>()
  for (const news of recentNews) {
    const names = extractModelNames(`${news.title} ${news.summary ?? ''}`)
    names.forEach(n => mentionedModels.add(n))
  }

  // 3. 过滤已有
  const existing = await prisma.model.findMany({
    where: { externalId: { in: [...mentionedModels] } },
    select: { externalId: true },
  })
  const existingIds = new Set(existing.map(m => m.externalId))
  const newModels = [...mentionedModels].filter(id => id && !existingIds.has(id))

  if (newModels.length === 0) return []

  // 4. 批量创建（标记 isPending）
  await prisma.model.createMany({
    data: newModels.map(id => ({
      externalId: id,
      name: id,
      provider: this.guessProvider(id),
      isPending: true,
    })),
  })

  return newModels
}
```

**修复**：

```ts
async fetchWithRetry<T>(fn: () => Promise<T>, maxRetries = 2): Promise<T | null> {
  for (let attempt = 0; attempt <= maxRetries; attempt++) {
    try {
      return await fn()
    } catch (e) {
      if (attempt === maxRetries) {
        console.warn(`[scraper] All retries failed:`, e)
        return null
      }
      await new Promise(r => setTimeout(r, 1000 * (attempt + 1)))
    }
  }
  return null
}
```

## 5. 关键代码片段

### 5.1 完整 `refreshOne`（修复版）

```ts
async refreshOne(modelId: string): Promise<ScrapedModelData | null> {
  const model = await prisma.model.findUnique({ where: { id: modelId } })
  if (!model) throw new Error('Model not found')

  // 策略 1：LiteLLM 统一（推荐主源）
  let priceInput: number | null = null
  let priceOutput: number | null = null
  let source: 'OFFICIAL' | 'AA' | 'MANUAL' = 'MANUAL'
  let note: string | undefined

  try {
    const litellmData = await litellmPricingCache.get()
    const p = litellmData.get(model.externalId)
    if (p && p.input > 0) {
      priceInput = p.input
      priceOutput = p.output
      source = 'OFFICIAL'
      note = `LiteLLM 路由报价（${new Date().toISOString().slice(0, 10)}）`
    }
  } catch (e) {
    console.warn(`[scraper] LiteLLM fetch failed for ${model.externalId}:`, e)
  }

  // 策略 2：官网（补充验证 LiteLLM）
  if (priceInput === null) {
    const officialData = await this.fetchFromOfficial(model)
    if (officialData?.priceInput) {
      priceInput = officialData.priceInput
      priceOutput = officialData.priceOutput ?? null
      source = 'OFFICIAL'
      note = officialData.note
    }
  }

  // 策略 3：AA 能力分
  let intelligence: number | undefined
  let speed: number | undefined
  try {
    const aaData = await this.fetchFromAA(model.externalId)
    if (aaData) {
      intelligence = aaData.intelligence
      speed = aaData.speed
      if (source === 'MANUAL') source = 'AA'
    }
  } catch (e) {
    console.warn(`[scraper] AA fetch failed for ${model.externalId}:`, e)
  }

  const hasAnyData = priceInput !== null || intelligence !== undefined

  // 更新
  await prisma.model.update({
    where: { id: modelId },
    data: {
      priceInput: priceInput ?? undefined,
      priceOutput: priceOutput ?? undefined,
      intelligence: intelligence ?? undefined,
      speed: speed ?? undefined,
      scoreSource: intelligence !== undefined ? 'AA-LIVE' : undefined,
      isPending: !hasAnyData,
    },
  })

  // 只在真有数据时记录快照
  if (hasAnyData) {
    await prisma.modelSnapshot.create({
      data: {
        modelId,
        priceInput: priceInput ?? 0,
        priceOutput: priceOutput ?? 0,
        intelligence,
        speed,
        source,
        note,
      },
    })
  }

  return { priceInput: priceInput ?? 0, priceOutput: priceOutput ?? 0, intelligence, speed, source, note }
}
```

## 6. 关键决策点

### 6.1 LiteLLM vs 官网 vs 静态表

| 方案 | 准确性 | 维护成本 | 推荐度 |
|---|---|---|---|
| **LiteLLM** | 高（实际路由价） | 低（统一） | ⭐⭐⭐ |
| **官网真抓** | 高（官方价） | 高（每月要修） | ⭐⭐ |
| **静态表** | 低（永不变） | 0 | 兜底 |
| **混合** | 最高 | 中 | ⭐⭐⭐（推荐） |

### 6.2 是否需要本地 AA 抓取

AA 没有公开 API（需要 key 或 scraper）。**MVP 阶段建议**：
- 内置静态表作为主源
- 每月人工更新一次
- 后续接 LMArena 替代（更开放）

### 6.3 是否需要 OpenTelemetry 接线

`.env.example` 已有 `@opentelemetry/*` 依赖（package.json），但代码未启用。

MVP 阶段**不上**。理由：聚合 Sentry/OTel 之后，再补。

详见报告 08。
