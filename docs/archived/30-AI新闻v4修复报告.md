# AI 新闻 v4 修复报告

**时间**：2026-08-30  
**版本**：v4.0（基于 v3 重构）

---

## 已修复问题

### 1. 布局重构（新闻主体）

**问题**：v3 的筛选区、统计按钮等次要元素太过突出，抢占了新闻的空间。

**修复**：
- 筛选区默认收起，点击「展开筛选」才显示
- 右上角仅保留 3 个精简按钮：展开筛选 / 数据统计 / 抓取新闻
- 新闻列表成为页面唯一焦点，占据最大视觉空间

### 2. 实时时钟（右上角）

**修复**：新增 `LiveClock` 组件

```
┌─────────────────────────────────────────────┐
│ AI 新闻聚合                    2026年8月30日 │
│                               23:53:12      │
│                                             │
│ [展开筛选] [数据统计] [抓取新闻]            │
└─────────────────────────────────────────────┘
         ↑ 年月日小（11px）  ↑ 时分秒大（18px bold）
```

实现细节：
- `setInterval` 每秒刷新
- `toLocaleTimeString(hour12: false)` 确保 24 小时制
- `tabular-nums` 数字等宽，不抖动

### 3. 封面图加载

**问题**：用户提供的一些图片链接失效。

**验证结果**：
- 用户提供的 `ali-ec.static.yximgs.com` 图片全部返回 400 错误
- 这是阿里云图片服务的图片，可能需要正确的 referer 或已过期

**当前处理**：
- 封面图从 RSS 的 `media:content` / `enclosure` / `<img>` 提取
- 所有封面图都有 `onError` 兜底 → 加载失败自动隐藏
- 卡片依然完整显示，只是没有图片

### 4. 更多新闻按钮

**修复**：累积加载式分页

```tsx
// 每次点「加载更多」，增加 PAGE_SIZE
const [page, setPage] = useState(0);
const PAGE_SIZE = 50;

const newsQuery = trpc.news.list.useQuery({
  limit: (page + 1) * PAGE_SIZE,  // 50 → 100 → 150 → ...
});
```

**UI**：

## 待解决

### OpenAI 新闻 403 问题
- OpenAI 网站有 Cloudflare 反爬
- 可能的解决方案：
  1. 使用 RSSHub 代理（rsshub.app/openai/news）
  2. 使用 Puppeteer 绕过（但复杂）
  3. 接受无法抓取（当前状态）

### 图片链接失效问题
- 用户提供的阿里云图片已过期
- 当前已有 `onError` 兜底
- 实际图片来源取决于各 RSS 源是否提供

### 关于「Cursor 取消供应 OpenAI」
- OpenAI 于 2026 年中宣布停止对部分中国区供应 API
- Cursor 使用的是 OpenAI API，可能受到影响
- 但 Cursor 本身也在支持 Anthropic、Google 等多模型，不影响使用
